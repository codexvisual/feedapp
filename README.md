# BeautyTalk Feed App

An Android social feed app built with **Eclipse (ADT) + Volley**, featuring image upload and a gallery feed.

## Features
- Feed with image posts
- Sign up / login (session manager)
- Volley multipart image upload
- Search gallery

## Requirements
- Eclipse + ADT plugin (or Android Studio with Eclipse project import)
- Android SDK

## Installation
1. Clone the repository
   ```
   git clone https://github.com/codexvisual/feedapp.git
   ```
2. In Eclipse: **File ▸ Import ▸ Existing Android Code Into Workspace** and select this folder
3. Build and run on a device/emulator

## Notes
- Older Eclipse-style project layout (`java/`, `res/`, `assets/`).
- Requires the server API endpoints referenced in `Constants.java` to work fully.
